# Domain tiers

Full discussion happened in chat; this is the reference copy.

## Tier 1 — v1, equal priority

1. Customer support triage
2. Trust & safety / content moderation
3. Email / communication classification
4. Sales / CRM
5. Security operations / alert triage
6. E-commerce

Chosen for: public data availability + clear commercial demand + good candidates for
distinct MoE experts (their input distributions don't overlap much, which is exactly
what should make routing pay off).

## Tier 2 — after v1 proves the routing thesis

7. Finance / insurance — claims triage, underwriting risk tier, expense classification
8. HR / recruiting — resume screening, candidate-fit scoring
9. Legal / compliance — contract clause classification, PII/redaction flags
10. DevOps / IT ops — incident severity, alert triage (overlaps with security-ops infra)
11. Healthcare — routing/triage only, never diagnosis (liability-heavy)
12. Education — rubric-based scoring, feedback classification

## Tier 3 — long tail

13. Government / public sector request routing
14. Real estate / property listing classification
15. Media / editorial tagging and quality scoring
16. Non-English coverage across all domains above (Laya's bar: 100+ languages)
